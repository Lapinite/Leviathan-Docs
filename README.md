## Scope

This repository is intended to document public-facing parts of Leviathan, including:

- Leviathan Launcher and client systems
- Microsoft, Xbox Live, XSTS, and Minecraft Services authentication behavior
- Minecraft installation, instances, profiles, Java runtimes, and launch configuration
- Launcher customization and supported user-facing features
- Public platform and developer documentation
- Integrations and webhooks
- Minecraft server tooling
- Security, privacy, release, troubleshooting, and support guidance

Documentation should clearly distinguish released functionality from development work and planned features.

## Documentation safety

Public documentation must not contain credentials, tokens, private keys, signing material, recovery material, personal information, private endpoints, internal infrastructure details, or machine-specific local development paths.

Administrative identifiers that are not required for legitimate public use should also remain private.
